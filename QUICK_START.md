## 📱 Responsive Design Specifications

### Breakpoints Optimized
```
320px  → Small Mobile (iPhone SE)
480px  → Mobile (iPhone 12)
768px  → Tablet (iPad Mini)
1024px → Desktop
1440px → Large Desktop
```

### Minimum Touch Targets
- All buttons: **48x48px** (accessibility standard)
- All links: **44x44px** minimum
- Menu items: **40px** spacing between

### Typography Scales
```
Desktop:  H1=48px, H2=36px, Body=16px
Tablet:   H1=40px, H2=28px, Body=15px
Mobile:   H1=32px, H2=24px, Body=14px
(All with line-height 1.7-1.8)
```

## 🎨 Design System Applied

### Color Palette
- **Primary**: White (#FFF) - Clean background
- **Text**: Dark (#111) - Readability
- **Accent**: Blue (#0066CC) - CTAs
- **Borders**: Light Gray (#EEE) - Subtle dividers
- **Card BG**: Barely Visible (#F9F9F9)

### Contrast Ratios (WCAG AAA)
- Text on white: **19:1** (well above 4.5:1 requirement)
- Links have sufficient contrast
- All interactive elements clearly visible

### Typography
- Font: "Outfit" (Google Fonts, modern + geometric)
- Weights: 300 (light), 400 (regular), 500 (medium), 600 (bold)
- Line-height: 1.7-1.8 (reduce eye strain)
