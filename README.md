# Alwin Madhu — Portfolio

Personal portfolio for Alwin Madhu, also known as Jeen (`j_e_e_n._` for creative work): developer, researcher, and builder of privacy-respecting software.

The site is a static GitHub Pages publication. It uses semantic HTML, clean permanent routes, JSON-LD structured data, `llms.txt`, `llms-full.txt`, `robots.txt`, and a sitemap so the same project facts are legible to people, search engines, and answer engines.

## Main routes

- Home: https://alwin-m.github.io/Portfolio/
- About: https://alwin-m.github.io/Portfolio/about/
- Projects: https://alwin-m.github.io/Portfolio/projects/
- Research: https://alwin-m.github.io/Portfolio/research/
- Contact: https://alwin-m.github.io/Portfolio/contact/

## Featured work

LIORA, SCREAM, Genome Sentinel, ROS-Cycle-Project, Megamind, and the Hathaway Algorithm research project.

## Deployment

Push to `main` to run `.github/workflows/pages.yml`, or use GitHub’s Pages settings to select the workflow as the deployment source.
