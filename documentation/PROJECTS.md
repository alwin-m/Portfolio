## 2. SCREAM — Peer-to-Peer Mesh Social Platform

- **Project Title**: SCREAM
- **Category**: Decentralized Systems / Resilient Mobile Communication
- **Co-Creators**: Alwin Madhu & Nejin Bejoy (2024 college project phase)
- **Lead Developer & Mobile Architect**: Alwin Madhu (solo transition to mobile P2P in May 2026)
- **Timeline**: 2024 (PHP/HTML Web App) → May 2026 (Mobile APK & P2P Mesh Transformation) → Present
- **Primary Tech Stack**: Wi-Fi Direct, Bluetooth Low Energy (BLE), Android (Native/APK), C++, Store-and-Forward Mesh Protocols
- **Architectural Rationale**: Conventional social media uses `User → Internet → Server → User`. SCREAM re-engineers this path into `User → Mobile Device → Nearby Device → Other Users`, enabling social communication when conventional Internet connectivity is restricted, severed, or unavailable (disasters, power failures, cellular outages).
- **Canonical Page URL**: `https://alwin-m.github.io/Portfolio/projects/project-scream.html`
