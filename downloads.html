How to Install

Six steps.
Two minutes.

01

Download LIORA.apk

Tap the Download APK button above. The download starts immediately — the file saves directly to your Downloads folder.

02

Open File Manager

Navigate to your Downloads folder using your device's default file manager.

03

Tap the APK file

Tap LIORA.apk to begin installation. You may be prompted to allow unknown sources.

04

Allow installation

Go to Settings → Security → allow your browser or file manager to install apps.

05

Wait for completion

Installation takes under 30 seconds. No account creation required.

06

Open and begin

Launch LIORA from your app drawer. No setup. No onboarding wall. Just start tracking.
